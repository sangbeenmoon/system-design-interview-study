## 핵심 내용 요약
- 수평적 규모 확장성을 위해서는 요청 , 데이터를 서버에 균등하게 나누는 게 중요하다.
- 단순 mod 연산 파티셔닝의 문제점
  - 슬롯의 수가 바뀌면 거의 대부분의 키가 재배치됨.
- 안정 해시
  - 해시 테이블의 크기가 조정될 때 평균적으로 k/n 개의 키만 재배치하는 해시 기술.
- 기본 구현 : 원 형태의 해시 공간에 서버를 분배해놓고, key 를 해시 공간에 올려놓고 시계 방향으로 해시 공간을 탐색. 가장 먼저 만나게 되는 서버에 key 를 저장.
- 문제점
  - 서버가 삭제되거나 추가될 경우 파티션 크기가 균등하지 않음.
  - 키의 균등 분포 달성 어려움. 
- 가상 노드 : 실제 서버 노드를 가리키는 가상의 노드 n 개. 가상 노드의 개수가 많아질수록 키의 분포는 점점 균등해진다.
