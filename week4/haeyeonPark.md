## 핵심 내용 요약
- 분산 kv저장소 -> CAP 모두를 만족할순 없다.
    - Consistency: 언제나 같은 데이터 
    - Availability: 일부 노드 장애 생겨도 응답 반환
    - Partition tolerance: 노드간 통신장애가 발생하더라도 시스템은 동작해야한다.
- P는 선택할수 있는 사항이 아니라 무조건 취하고, CP 혹은 AP 시스템을 선택해야한다. 
- CP: 문제 생기면 write 포기. AP: 문제 생겨도 일단 write 진행.
- W + R > N 이어야 강한 일관성이 유지된다.
- 일관성이 깨지는 경우 -> 데이터 버져닝(벡터시계)으로 해결할수 있다. 

- 분산 시스템을 위한 유일 ID 생성 방법 -> uuid(128bit제약), 티켓서버, 스노플레이크 
- 스노 플레이크: 타임스탬프 + 데이터센터/서버 id + 일련번호 조합으로 id 만들기. -> 타임스탬프의 길이 제한에 유의해야함.
